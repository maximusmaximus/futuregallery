# Artwork overlay: investigate button

Locked interaction from product direction.

When a piece is recognized in the camera, or shown on a public catalog card:

- Attach a button to the bottom right of the artwork.
- Place it slightly below the artwork bounds so it does not cover the piece.
- Label: Add to investigate (or a plus icon with that accessible name).
- Action: add the piece to the visitor's items to investigate further.
- The tray can hold multiple pieces while they keep scanning.
- If the piece is already in the tray, the button switches to Added / Remove.
- Do not use a checkbox on the artwork itself for this control.

This is the multi-select path for review later.
